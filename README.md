# Stock Lab — 나만의 투자 실험실

가상 기업 300개와 가상 자금 1,000만 원으로 매수·매도, 주문 방식, 자금 배분을 배우는 정적 웹사이트입니다. 한국형 150종·미국형 150종을 10개 업종으로 나눕니다. 모든 기업·시세·환율·거래량·뉴스는 생성 데이터이며 실제 증권 주문, 결제 또는 시세 API 연결은 없습니다.

## 빠르게 열기

압축을 풀고 **`StockLab.html`**을 최신 Chrome, Edge 또는 Safari로 엽니다. 이 파일에 화면·스타일·코드를 모두 포함했습니다. 외부 API 키, 서비스 가입, 설치 과정이 없습니다. 파일 실행 환경에 따라 기기 저장소나 암호화 기능이 제한되면 아래 로컬 서버 또는 GitHub Pages 주소를 이용하세요.

개발용 `index.html`은 여러 파일을 읽으므로 더블클릭 대신 로컬 서버나 GitHub Pages에서 엽니다.

```bash
cd /Users/llouis/Documents/ChatGPT/LLouis/StockLab
npm run dev
```

기본 주소: `http://127.0.0.1:4173`. 실제로 압축을 푼 경로가 다르면 `cd` 경로를 바꿉니다. Node.js 22 이상을 사용합니다. 의존 패키지가 없어 `npm install`은 필요하지 않습니다. 로컬 서버는 `Ctrl+C`로 종료합니다.

## GitHub Pages에 올리기

### 명령어 한 줄로 저장소 생성부터 배포까지

현재 작업 폴더가 그대로 있다면 터미널에서 다음 한 줄을 실행합니다.

```bash
bash /Users/llouis/Documents/ChatGPT/LLouis/StockLab/deploy.sh
```

다른 경로에 압축을 풀었다면 그 폴더 안에서 `bash deploy.sh`를 실행합니다. 처음에는 GitHub 브라우저 로그인 안내가 나올 수 있습니다. 인증을 마치면 로그인한 계정에 **공개 저장소 `StockLab`**을 만들고, 소스 업로드 → Pages 활성화 → 배포 완료 확인 → 사이트 열기까지 진행합니다. Node.js 22 이상과 GitHub CLI(`gh`)가 필요합니다.

이름을 바꾸려면 `bash deploy.sh StockLab2`처럼 저장소 이름을 전달합니다. 이후 같은 명령어를 실행하면 연결된 저장소를 업데이트합니다. 같은 이름의 다른 저장소나 다른 `origin`, 스테이징된 변경이 있으면 덮어쓰지 않고 중단합니다. StockLab 폴더 자체에 Git 저장소를 생성하므로 상위 폴더의 다른 파일은 커밋하지 않습니다.

기존 GitHub 인증 토큰에 워크플로 업로드 권한이 없다는 오류가 나오면 `gh auth refresh -h github.com -s workflow`로 인증 권한을 갱신하고 다시 실행합니다. 스크립트는 비밀번호나 토큰을 소스에 기록하지 않습니다.

### 전체 소스를 올리고 자동 배포

1. GitHub에 새 저장소를 만듭니다. 예: `StockLab`. 무료 GitHub Pages 이용은 공개 저장소 기준입니다.
2. 이 폴더 **안의 내용 전체**를 저장소 루트에 올립니다. 루트에 `index.html`, `src/`, `styles/`, `.github/`가 있어야 합니다. `StockLab/StockLab/index.html`처럼 한 단계 더 감싸지 않도록 합니다.
3. 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
4. 기본 브랜치 `main`에 커밋·푸시합니다. 이미 푸시했다면 **Actions → Deploy Stock Lab to GitHub Pages → Run workflow**를 실행합니다.
5. Actions의 테스트·빌드·배포 작업이 성공하면 배포 주소로 접속합니다. 저장소 이름이 `StockLab`이면 주소 형식은 `https://<GitHub아이디>.github.io/StockLab/`입니다.

포함된 `.github/workflows/pages.yml`이 정적 파일을 빌드하고 자동 테스트 후 배포합니다. 브랜치가 `main`이 아니라면 이 파일의 `branches` 값을 실제 브랜치로 바꿉니다. 브라우저 드래그 업로드에서 숨김 폴더 `.github`가 빠지지 않도록 주의하세요.

새로 만든 빈 저장소에 터미널로 올리는 예시:

```bash
cd /실제로/압축을/푼/StockLab
git init -b main
git add .
git commit -m "Build Stock Lab paper trading simulator"
git remote add origin https://github.com/<GitHub아이디>/StockLab.git
git push -u origin main
```

위 `<GitHub아이디>`는 실제 아이디로 바꿉니다. 기존 저장소를 사용한다면 중복으로 `git init`이나 `remote add`를 실행하지 말고 해당 저장소의 Git 설정을 유지하세요.

### 파일 하나만 올리는 간단한 배포

`StockLab.html`의 이름을 **`index.html`**로 바꿔 빈 저장소 루트에 올립니다. **Settings → Pages → Source → Deploy from a branch → main / (root)**로 선택하면 단일 HTML로도 운영할 수 있습니다. 이 방식에는 빌드나 Actions 파일이 필요하지 않습니다. 이후 소스를 수정했다면 `npm run build`로 단일 HTML을 다시 생성해 교체합니다.

저장소 하위 경로에서도 동작하도록 소스의 경로는 모두 상대 경로이며, 화면 이동은 `#market`, `#portfolio`, `#journal`, `#learn`을 사용합니다.

## 처음 연습하는 순서

1. `로그인 / 가입 → 프로필 만들기`에서 아이디와 8자 이상의 비밀번호를 정합니다. 같은 브라우저에 여러 프로필을 만들 수 있습니다.
2. 관심 있는 가상 기업을 검색하고 별을 눌러 관심 목록에 추가합니다.
3. 한국형 종목을 시장가로 1주 매수하고 `내 자산`에서 현금·수수료·보유 수량을 확인합니다.
4. 현재 가격보다 낮은 지정가 매수를 등록해 대기 주문, 예약 금액, 취소를 연습합니다.
5. 미국형 종목을 매수하려면 `가상 환전`에서 원화를 달러로 바꿉니다.
6. 체결된 거래는 `매매일지`에서 이유와 감정을 기록합니다. `학습 노트`에서 관련 개념을 확인합니다.
7. 프로필 메뉴에서 암호화 백업을 내려받습니다. 배포 주소나 기기를 바꿀 때는 이 백업과 비밀번호로 복원합니다.

## 저장 방식과 비밀번호

이번 버전은 사용자가 선택한 **기기 내 저장 방식**입니다. 서버 계정과 자동 기기 동기화가 아닙니다. 접속한 웹사이트 주소와 브라우저에 따라 저장 공간이 달라집니다. `file:`로 연 단일 HTML과 GitHub Pages, Chrome과 Safari, PC와 휴대폰 사이에서는 백업·복원이 필요합니다.

- 거래 기록·메모·학습 진도는 비밀번호에서 유도한 키로 **AES-GCM 256비트** 암호화합니다.
- 키 유도는 **PBKDF2-SHA-256 210,000회**, 프로필별 난수 salt 16바이트, 저장할 때마다 새 IV 12바이트를 사용합니다.
- 비밀번호 자체를 저장하지 않습니다. 암호화 키는 로그인한 탭 메모리에만 보관합니다. 새로고침하면 다시 로그인합니다.
- 프로필 아이디·저장 시각·암호화 형식은 복원에 필요한 일반 메타데이터로 저장합니다.
- **비밀번호를 잊으면 복구할 수 없습니다.** 백업 파일도 원래 비밀번호가 필요합니다.
- 브라우저 데이터 삭제, 비공개 모드 종료, 파일 이동 등의 상황에서 기록을 잃을 수 있으므로 백업을 사용합니다.
- 같은 프로필은 한 탭에서 사용합니다. 브라우저 Web Locks와 버전 검사를 사용하고 다른 탭의 변경을 감지하면 다시 로그인하도록 안내합니다.
- 소스와 실행 환경을 사용자가 제어할 수 있으므로 대회·순위 서비스의 부정행위 방지 수단은 아닙니다.

수수료와 환전 비용은 학습을 위한 가상 설정이며 실제 증권사 요율이 아닙니다. 평가손익은 매수 수수료를 포함한 원가와 현재 가격으로 계산하고 미래 매도 수수료는 차감하지 않습니다. 미국형 개별 종목의 손익은 달러 기준, 계좌 전체는 현재 가상 환율로 원화 환산합니다.

## 가격 생성 방식

`src/market.js`는 정해진 문자열 시드에서 균등 난수를 생성하고 Box–Muller 변환으로 정규 난수를 만듭니다. 여러 시간 척도의 잡음을 부드럽게 보간한 후 다음 요소를 합칩니다.

1. 같은 시장의 기업이 공유하는 시장 공통 요인
2. 같은 업종이 공유하는 업종 요인
3. 기업마다 다른 장기·중기·단기·미세 변동
4. 시간에 따라 달라지는 변동성 수준
5. 업종별 가상 뉴스 충격과 점진적인 효과 감소

가격은 `기준 가격 × exp(합성 요인)`으로 만들어 양수를 유지하고 통화 단위로 반올림합니다. 실제 하루 경과는 `가상 48일`에 해당합니다. 고정된 기준 시각과 결정론적 함수 덕분에 브라우저를 닫아도 같은 시각의 가격을 재현할 수 있습니다. 과거 차트는 동일한 가격 함수에서 구간을 표본 추출합니다.

기하 브라운 운동이나 실제 거래소를 그대로 복제한 모델은 아닙니다. 장기 무작위 추세를 무한히 누적하지 않는 합성 요인 모형이므로 실제 주식의 장기 성장·파산·배당·기업 실적을 추정하지 않습니다. **매매 절차와 기록 습관을 익히기 위한 시뮬레이터**이며 이곳의 성과를 실전 수익률로 해석하지 않습니다.

## 개발·테스트

```bash
npm run build
npm test
```

빌드는 배포용 `dist/`와 단일 파일 `StockLab.html`을 생성합니다. `dist/`에는 운영에 필요한 정적 파일만 들어갑니다. 원본 수정 후에는 빌드를 다시 실행합니다.

자동 테스트는 생성 데이터 일관성, 통화 단위, 차트 OHLC, 수수료·원가·잔고 계산, 과도한 주문 거부, 예약·취소·만료, 재접속 체결, 환전, 암호화·오류 비밀번호·백업·충돌 보호, 화면 생성과 주요 컨트롤러 흐름을 확인합니다. 화면 생성 테스트는 Node VM에서 실행하며 실제 브라우저 렌더링 테스트를 대신하지 않습니다.

제작 환경에서 로컬 서버의 포트 열기와 브라우저의 `file:` 주소 접근이 제한되어 **실제 브라우저 및 모바일·태블릿의 시각·터치 검수는 완료하지 못했습니다.** 반응형 CSS는 포함했으며, 실제 GitHub Pages 배포도 아직 수행하지 않았습니다.
